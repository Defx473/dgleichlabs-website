2. Hosting über GitHub Pages

Diese Website ist eine rein statische Seite und wird über GitHub Pages ausgeliefert. Anbieter ist die GitHub, Inc. (Unternehmen mit Sitz in den USA), ein Unternehmen der Microsoft-Gruppe.

Beim Abruf einer GitHub-Pages-Website werden technisch erforderliche Verbindungsdaten verarbeitet. GitHub dokumentiert dazu ausdrücklich: Beim Besuch einer GitHub-Pages-Website wird die IP-Adresse des Besuchers protokolliert und zu Sicherheitszwecken gespeichert – unabhängig davon, ob der Besucher bei GitHub angemeldet ist.

GitHub nennt in dieser Dokumentation keine konkrete Speicherdauer für diese Protokolle. Eine Frist wird deshalb hier nicht genannt; sie ist vor der Veröffentlichung mit GitHub abzuklären. Ebenso ist zu klären, ob mit GitHub ein Vertrag zur Auftragsverarbeitung nach Art. 28 DSGVO geschlossen ist oder geschlossen werden muss – das von GitHub angebotene „GitHub Data Protection Agreement“ ist Bestandteil des GitHub-Kundenvertrags und gilt nicht automatisch für kostenlose Konten. Dieser Punkt ist vor der Veröffentlichung zu entscheiden.

3. Server-Logdaten

Bei jeder Anfrage an einen Webserver entstehen technisch unvermeidbar Verbindungsdaten. Belegt sind für GitHub Pages die oben genannte IP-Adresse sowie die Merkmale, die dein Browser bei einer HTTP-Anfrage ohnehin übermittelt (etwa Datum und Uhrzeit des Abrufs, die angeforderte Datei, der verwendete Browser und – falls vorhanden – die zuvor besuchte Seite).

Diese Verarbeitung ist für die Auslieferung der Seite und den sicheren, stabilen Betrieb erforderlich. Wir selbst führen keine eigenen Logfiles und werten die beim Hoster anfallenden Daten nicht aus; wir haben auf diese Protokolle keinen Zugriff.

Konkrete Speicherfristen werden nicht genannt, weil GitHub für die Pages-Protokolle keine Frist veröffentlicht. Erfundene Angaben wären irreführend.

Diese Website enthält kein Kontaktformular. Kontakt erfolgt über den E-Mail-Link {{ email }}. Beim Anklicken öffnet sich dein eigenes E-Mail-Programm; erst mit dem Absenden werden Daten verarbeitet.

Die übermittelten Angaben – mindestens deine Absenderadresse, der Inhalt der Nachricht und die Übermittlungsdaten – verwenden wir ausschließlich, um die Anfrage zu bearbeiten.

Für das Postfach {{ email }} wird das E-Mail-Angebot der STRATO GmbH (Otto-Ostrowski-Straße 7, 10249 Berlin, Deutschland) genutzt. Die E-Mail-Verarbeitung erfolgt damit bei einem Anbieter mit Sitz in Deutschland.

Da von der Website selbst keine Cookies gesetzt werden und keine Einwilligung erforderlich ist, gibt es keinen Cookie-Banner.
